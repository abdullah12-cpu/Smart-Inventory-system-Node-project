# Response Formatting Rules

1. **Markdown Format**:
   - Always format table data in GitHub-flavored markdown with clean column headers.
   - Use bold text `**Name**` for product names, supplier names, and order numbers.

2. **Currency & Numbers**:
   - Format monetary values in PKR currency format: `Rs X,XXX,XXX`.
   - Format stock counts with unit labels: `X units`.

3. **Status Badges**:
   - Represent statuses clearly: `APPROVED`, `PROCESSING`, `SHIPPED`, `DELIVERED`, `PENDING`.

4. **Conciseness**:
   - Keep conversational fluff minimal.
   - Directly present data tables and action results.
